# Chrome Web Store descriptions

Use the **Summary** in the short summary field and the **Detailed description** in the description field for each matching language in the Chrome Web Store Developer Dashboard. Each summary is within the 132-character limit.

## English (`en`)

**Summary**

```text
Open your Google Search query in Google Maps with a dedicated Maps tab.
```

**Detailed description**

```text
This extension simply adds the “Maps” tab back to Google Search results for users in Europe.

Based on the query in the Google search bar, the “Maps” tab opens Google Maps with the search phrase and displays matching places.

The extension does not collect user data, helping protect users’ privacy and security.

For more information, please get in touch.
```
