
# GMAPPS

Google Maps Redirect is a Chrome extension that adds a Maps tab between All and Images in supported Google search results. Click it to search the current phrase in Google Maps. The popup lets you choose automatic, Polish, or English labels.

## Installation

Download and install package directly from Chrome Web Store: 
[link](https://chromewebstore.google.com/detail/google-maps-redirect/daaaldhakajelaajhlckpjnejaadlmff?hl=pl&authuser=0&fbclid=IwZXh0bgNhZW0CMTAAAR3VqnZ3dtmQ1lJtAs1tRLwHczn5A8xnlC7-d94wll6nA9VWOfn38l9r8gI_aem_AWpEL_sSNKr_IqgZlr7Z1WFZIn411-H5rHE-LWT7VJ5_lZrR7Y15TACZpp-yJHcXrWy15vyHoO95GhGpYtPj9mJ3)

Or

Download from github and navigate to:
```bash
chrome://extensions/ 

```
and click the: 
- "Load unpacked extension..." 
button. Navigate to and select this directory. The extension adds a Maps tab to supported Google search results.
